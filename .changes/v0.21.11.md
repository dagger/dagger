## v0.21.11 - 2026-10-21

### Fixed
- Fix Go module codegen failing with `import cycle not allowed` in OpenTelemetry packages by @sipsma in https://github.com/dagger/dagger/pull/14646 \
  Generated modules now pin `github.com/dagger/otel-go` and `go.opentelemetry.io/otel/sdk`
  instead of resolving them to their latest versions, which pulled
  `go.opentelemetry.io/otel` v1.47.0 into a cycle with the pinned `otel/log` v0.16.0.
- Fix engine memory growth from schema servers retained after their sessions end by @sipsma in https://github.com/dagger/dagger/pull/14756 \
  Cached results, types, module resolvers and module dependency schemas no longer keep
  session schema servers alive, so long-running engines stop accumulating heap until OOM-killed.
