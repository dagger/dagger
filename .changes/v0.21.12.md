## v0.21.12 - 2026-11-17

### Fixed
- Fix Dockerfile `COPY` reading the whole image and keeping a hash record of it in engine memory by @sipsma in https://github.com/dagger/dagger/pull/15040 \
  A plain `COPY` is now keyed on its parent, its arguments and the content of its sources,
  as BuildKit does, and a `COPY --from` of a single file no longer records the source stage's
  whole filesystem. Engines running many Dockerfile builds no longer grow until OOM-killed.
- Fix gracefully stopped services being force-killed when a binding detaches during shutdown by @sipsma in https://github.com/dagger/dagger/pull/15069 \
  A detach of a service that is already stopping is now a no-op, and a graceful stop joins one
  already in flight instead of sending another SIGTERM followed by a SIGKILL 10s later.
- Fix execs escaping the engine pod's CPU and memory limits under Kubernetes by @sipsma in https://github.com/dagger/dagger/pull/15096 \
  The engine now runs in its own cgroup namespace rooted at its container's cgroup, so execs
  nest under the pod's limits as they do under Docker. An exec that exceeds the memory limit
  is OOM-killed on its own and the engine keeps running.
- Fix setting `GitRepository` and `GitRef` arguments from `.env` user defaults by @marcosnils in https://github.com/dagger/dagger/pull/15155 \
  These failed with `Address has no such field: "gitrepository"` while the same value passed
  as a flag worked.
