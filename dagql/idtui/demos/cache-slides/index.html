Hits divided by all calls that consulted the cache. Uncached calls are excluded.

results restored from cache ÷ total cache lookups
⏱

Wall time

Whole-workflow makespan. Parallel branches are never added together.

cold duration − warm duration
⚙️

CPU

Cumulative CPU time across every measured container and every core.

Σ cold CPU − Σ warm CPU
▥

Peak memory

Largest sum of memory used by containers that were active at the same time.

cold concurrent peak − warm concurrent peak
⇅

Network

Received and transmitted bytes are accumulated and compared separately.

RX saved = Σ cold RX bytes − Σ warm RX bytes

What we actually compute

  • Use each sample’s span ID to recover when that container started and stopped.
  • Rebuild intervals and sum only containers active at each point in time.
  • Take the maximum aggregate value for each run, then subtract warm from cold.
  • Samples arrive about every 5 seconds, so brief spikes may be missed.
  • “Peak saved” is an observed estimate—not a guarantee that an OOM was prevented.
