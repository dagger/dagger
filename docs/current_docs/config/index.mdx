# Configuration

How a workspace is configured — the settings in `dagger.toml`, how modules are wired to each other, and how values change per environment.

- **[Environments](./environments.mdx)** — named overlays for staging, production, and per-developer values.
- **[User configuration](./user.mdx)** — personal overrides that stay out of the repository.
- **[Module wiring](./module-wiring.mdx)** — connect one module's output to another module's settings.
- **[Reference](./reference/index.mdx)** — schemas for the files that configure Dagger.
