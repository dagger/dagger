# Introduction

Dagger is a CI orchestration engine. It runs project workflows in containers.

Use modules to add workflows to a project. Run the same workflows on your computer or in Dagger Cloud.

Dagger caches workflow operations. Dagger also records a trace for each run.

## Get started

Complete these guides in order:

1. [Install Dagger](./install.mdx). Install the Dagger CLI and a container runtime.
2. [Try Dagger](./try-dagger.mdx). Run Checks in an example project.
3. [Quickstart](./quickstart.mdx). Configure Dagger in your project.
4. [Set up Cloud Checks](./cloud-checks.mdx). Run your Checks after Git events.

If your project already uses Dagger, see the [CLI guides](../cli/checking.mdx).

## What you can do

Use official modules without writing module code.

### Lint and format across your stack

## Key features

**Programmable.** Define custom workflows in Go, Python, TypeScript, or PHP.

**Local-first.** Run the same workflows before and after you push.

**Automatic tracing.** Dagger records each workflow operation. You do not need instrumentation code.

**Interactive debugging.** Open a terminal in a workflow operation.

**Incremental execution.** Dagger reruns an operation only when its inputs change.

**Agent support.** Agents can run Dagger Checks in their development loop.

**Secrets.** Connect Dagger to your secrets provider.

**Services.** Start service dependencies when a workflow needs them.
