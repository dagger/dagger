# Platform Guides

The [Quickstart](../quickstart.mdx) gets any project to its first passing Checks. A platform guide continues from there for one kind of project. It configures the modules for that platform and extends them with a small module of your own where the platform needs it.

Complete the Quickstart in your project, then pick its guide:

| Guide | What it covers |
| --- | --- |
| [Daggerize a Go Project](./go/index.mdx) | Run tests, lint, and generators with the Dagger module for Go, and give end-to-end tests the runtime and services they need by wiring a small Dang module into it. |

If there is no guide for your platform yet, the [module reference](../../reference/modules/index.mdx) lists the official modules and their settings.
