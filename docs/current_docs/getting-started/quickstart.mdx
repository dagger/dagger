# Quickstart

In this guide, you will configure Dagger in your project. You will install suitable modules and run at least one Check.

Complete [Try Dagger](./try-dagger.mdx) before you start.

## Open your project

Open a terminal at the root of your project:

```shell
cd path/to/your/project
```

Replace `path/to/your/project` with the path to your local checkout.

Verify that the Git `origin` remote points to the GitHub repository that you want to configure:

```shell
git remote get-url origin
```

## Install modules

Scan the project for suitable modules:

```shell
dagger setup
```

Select the modules that match your project. Then select **Install selected**.

If Dagger migrates an old configuration, run `dagger setup` again.

### If setup finds no modules

If Dagger reports `No recommendations`, search for a module that supports a tool in your project.

For example, use these commands if the project uses ESLint:

```shell
dagger search eslint
dagger install github.com/dagger/eslint
```

The first install creates `dagger.toml` at the repository root.

Install only modules that match tools in the project.

## Configure modules if necessary

Most modules use suitable default settings. List the available settings:

```shell
dagger settings
```

Change a setting only when it applies to the project.

For example, use this command if you installed ESLint and the project uses Yarn:

```shell
dagger settings eslint packageManager yarn
```

The settings are stored in `dagger.toml`. They apply to all users of the workspace.

## Verify the workspace

List the workspace Generators:

```shell
dagger generate -l
```

If the command lists Generators, run them:

```shell
dagger generate
```

Review the changes. Apply them when requested.

List the Checks:

```shell
dagger check -l
```

Verify that the list contains at least one Check that validates your project.

If the list has no applicable Checks, install another suitable module.

Run the Checks:

```shell
dagger check
```

You are done when at least one Check runs and all Checks pass.

Keep all files that Dagger created or changed.
