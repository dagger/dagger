# Configuration files

Schemas for the files that configure Dagger.

| File | Configures |
| --- | --- |
| [`dagger.toml`](./dagger-toml.mdx) | A workspace: its installed modules, their settings, and environment overlays. |
| [`engine.json`](./engine-json.mdx) | The engine: log level, registries, security, garbage collection, and resource metrics. Also lists the few settings that are only in `engine.toml`. |
