# API

The CLI, modules, checks, generators, and services all run on one GraphQL API served by the engine.

- [Reference](./reference/index.mdx) lists every type and function in the API, generated from the engine schema.
- [Clients](./clients/index.mdx) covers calling the API from your own program, either through a generated client bound to a module or through the standalone client library for your language.
