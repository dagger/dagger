## sdk/go/v1.0.0-beta.19 - 2026-10-19

This SDK uses 🚙 Engine + 🚗 CLI version `v1.0.0-beta.19`. [See what changed in that release](https://github.com/dagger/dagger/releases/tag/v1.0.0-beta.19).

🐹 https://pkg.go.dev/dagger.io/dagger@v1.0.0-beta.19

### Changed
- Require the modules that generated Dagger module code imports by @sipsma in https://github.com/dagger/dagger/pull/14450 \
  `github.com/dagger/otel-go` and `go.opentelemetry.io/otel/sdk` are now
  required through a build-tagged package, so generated modules pin them
  instead of resolving the newest version over the network. This raises the
  minimum `go.opentelemetry.io/otel` version to v1.43.0. Programs using the SDK
  don't compile the new requirements.
- Generated clients remember an object's ID after fetching it, so passing the by @sipsma in https://github.com/dagger/dagger/pull/14593 \
  same object to many calls no longer asks the engine for its ID each time.
  Objects built through fields marked `@reevaluate`, such as never-cached
  module functions, still fetch their ID on every use, so each use evaluates
  them again.

### Dependencies
